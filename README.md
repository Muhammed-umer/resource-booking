# Resource Booking

College resource booking portal for Government College of Engineering, Erode:
departments request the Auditorium, Seminar Hall or Guest House, and the
facility's admin approves, rejects or cancels.

The application lives in [`resource-booking-next/`](resource-booking-next/) —
a Next.js 16 app with PostgreSQL (Drizzle ORM), email/password sign-in and
email notifications. See its README for setup and commands.
